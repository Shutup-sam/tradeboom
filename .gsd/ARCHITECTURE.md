## Data Flow
1. **Inputs:** User interacts with UI inputs (Forms, Sizing Sliders, Pattern Quiz buttons).
2. **Client Validation:** Form submissions trigger Next.js Server Actions with loading loaders.
3. **Server Validation:** Server parses Zod constraints, sanitizes data structures, and persists entries to Supabase Postgres tables.
4. **Fallback Storage:** If Supabase is unconfigured, entries fall back to local JSON files in `data/`.
5. **Push Alerts:** Server triggers async Telegram REST calls, pushing notification cards directly to the admin.
