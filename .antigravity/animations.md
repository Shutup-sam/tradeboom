# Trade Boom - Animations Specification

### 1. Spring Physics Settings
- Use high-performance springs for cursor tracking and button magnets:
  - `stiffness: 150`
  - `damping: 15`
  - `mass: 0.1`

### 2. Fade Reveal Timings
- Standard stagger reveal delays: `0.08s` delay offset per child element.
- Transition curves: Use ease-out or custom cubic-bezier curves like `[0.16, 1, 0.3, 1]` for ultra-premium slide movements.
