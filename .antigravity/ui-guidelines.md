# Trade Boom - UI Guidelines

### Typography
- **Primary Body Font**: Inter (`--font-inter`)
- **Display Serif Font**: Instrument Serif (`--font-instrument-serif`)
- **Mono Font**: JetBrains Mono (`--font-jetbrains-mono`)

### Core Color System
- **Backgrounds (Ink)**:
  - Base: `bg-ink-950`
  - High Contrast: `bg-ink-900`
- **Primary Accents (Electric Blue)**:
  - Standard: `text-electric-400`, `bg-electric-500`
- **Positive Indicators (Emerald Green)**:
  - Standard: `text-emerald-400`, `bg-emerald-500`
- **Alert / Warning / Reversal (Crimson Red)**:
  - Standard: `text-crimson-400`, `border-crimson-500/20`

### Glassmorphism Spec
- **Panels**: `bg-white/[0.02] border border-white/[0.08] backdrop-blur-md`
- **Hover States**: `bg-white/[0.04] border border-white/[0.12]`
